# Sweet Morning Lofi

A polyglot pipeline that generates and publishes daily lofi content to YouTube. Three independent subprojects share a single `.env`, a single `assets/` folder, and a single YouTube channel.

| Subproject | Language | What it produces |
|---|---|---|
| `lofi/`   | Python | Long-form lofi videos (45–90 min). Suno API for music, AI for the background image, FFmpeg for the render, scheduled upload via YouTube Data API v3. |
| `shorts/` | Go     | YouTube Shorts (1080×1920). Pollinations for the image, edge-tts for the narration, FFmpeg for the final render. |
| `auth/`   | Go     | One-time OAuth2 flow against the YouTube Data API plus a `diag` tool for troubleshooting credentials. |

## Prerequisites

| Tool | Version | Used by |
|---|---|---|
| Go | 1.25+ | `shorts`, `auth` |
| Python | 3.10+ | `lofi` |
| FFmpeg + FFprobe | any | `lofi`, `shorts` |
| Suno API (Docker) | — | `lofi` (music generation) |
| Google Cloud project | — | `lofi` (YouTube upload) |

## Configuration

A single `.env` at the repo root is read by all three subprojects.

```env
# Weather forecast (openweathermap.org, free tier)
OPENWEATHER_API_KEY=

# Suno API (cookie from suno.com)
SUNO_COOKIE=
SUNO_API_URL=http://localhost:3000

# YouTube OAuth2 — generated by `auth/`
YOUTUBE_CLIENT_ID=
YOUTUBE_CLIENT_SECRET=
YOUTUBE_REFRESH_TOKEN=
```

See [`.env.example`](.env.example) for the full list.

## Usage

### One-time YouTube auth

```powershell
make auth-run
```

Opens a browser for OAuth consent, prints the three lines to paste into `.env`.

### Generate long lofi videos (Python)

```powershell
make lofi
```

For each requested day:

1. Generate the background image with Stable Diffusion (local ComfyUI).
2. Generate music tracks via the Suno API and download them.
3. Concatenate tracks into a single audio file (FFmpeg).
4. Render the final MP4 (FFmpeg, image + audio + text overlay).
5. Schedule the upload at `publish_hour` UTC (skipped if YouTube credentials are missing).

### Generate Shorts (Go)

```powershell
make shorts-run
```

Defaults:

- 1080×1920 at 30 fps
- Image source: Pollinations (1080×1920, lanczos disabled — upscaling only softens output)
- Voice: `pt-BR-AntonioNeural` via edge-tts, rate `-5%`
- Concurrency: serial by default to avoid Pollinations 402 rate limit, 8 s spacing

Flags are listed in `shorts/main.go`.

### Diagnose YouTube credentials

```powershell
make auth-diag
```

## Project layout

```
sweet-morning-lofi/
├── auth/               Go module: YouTube OAuth + credential diagnosis
│   ├── cmd/auth/       Browser-based OAuth flow
│   └── cmd/diag/       Token diagnosis
├── shorts/             Go module: YouTube Shorts pipeline
│   ├── main.go
│   └── internal/shorts/
├── lofi/               Python: long lofi video pipeline
│   └── generate_videos.py
├── assets/             Shared fonts and images
├── output/             Generated videos and audio (gitignored)
├── Makefile            One-line entry points per subproject
├── .env / .env.example
└── README.md
```

## Notes

- Each subproject has its own `go.mod` (or no module manager, for Python). They are kept under one repo because they share assets, credentials, and the target channel.
- `_archive/` (gitignored) holds the previous monolithic pipeline, kept for reference until the new structure is fully ported.
